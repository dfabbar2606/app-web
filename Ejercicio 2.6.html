HTML
Es el estándar utilizado para estructurar y presentar el contenido de las páginas web.
CSS
Es el lenguaje que se encarga de los aspectos visuales y de estilo
JavaScript
Es un lenguaje de programación interpretado y orientado a los objetos basados en prototipos
URl
Es la dirección única que se utiliza en internet para localizar y acceder a un recurso específico
HTTP
Es el protocolo de comunicación de la capa de aplicación que permite el intercambio de información
